<h1 align="center">ASRA</h1>

<p align="center">Farzandingiz uchun ishonchli himoya</p>

<p align="center"><a href="https://asrafamily.uz">asrafamily.uz</a></p>

ASRA — ota-onalar uchun ilova. Ota-ona qoidalarni belgilaydi, ular bola telefonida ishlaydi va internet uzilganda ham kuchda qoladi.

## Imkoniyatlar

- **Ekran vaqti:** kunlik limit, uyqu rejimi va dars vaqti
- **Ilova qoidalari:** har bir ilovaga limit yoki blok
- **Joylashuv:** xaritada joriy joylashuv va xavfsiz hududlar
- **Qidiruv va YouTube:** bola nimani qidirgani va qaysi videolarni ko’rgani
- **So’rov va ruxsat:** bola vaqt so’raydi, ota-ona ilovada yoki Telegram orqali hal qiladi
- **SOS:** bir tugma bilan ota-onaga xabar

Shaxsiy yozishmalar matni o’qilmaydi. Ma’lumot sotilmaydi, reklama yo’q.

## Texnologiyalar

Flutter (Android, iOS) · Kotlin · NestJS · PostgreSQL/PostGIS · Redis

## English

ASRA is a parental control app. Parents set the rules, and the rules are enforced on the child’s phone, even offline. It covers screen time, app limits, location and safe zones, search and YouTube history, time requests, and an SOS button. Private message contents are never read.

This repository holds the public website. The app and server source code are private.
